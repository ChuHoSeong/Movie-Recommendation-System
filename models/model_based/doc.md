# Model-Based Collaborative Filtering (Funk SVD)

## 1. 담당 역할 및 목표

MovieLens 100K의 사용자–영화 평점 데이터를 이용하여 **편향을 포함한 행렬 분해(Biased Matrix Factorization, Funk SVD)** 모델을 구현한다. 사용자와 영화의 잠재 요인(latent factors)을 학습해 미관측 평점을 예측하고, 여러 하이퍼파라미터의 성능을 비교한다. 전처리 담당자의 공통 데이터 분할을 그대로 사용하며, Content-based 모델과의 점수 결합은 통합 담당자의 역할이다.

## 2. 사용 데이터

- 경로: `data/100k/preprocessed/`
- 학습 데이터: `train.csv` — **70,012건**
- 검증 데이터: `val.csv` — **9,988건**
- 테스트 데이터: `test.csv` — **20,000건**
- 모델 입력 컬럼: `u`(0부터 시작하는 사용자 내부 인덱스), `i`(0부터 시작하는 영화 내부 인덱스), `rating`(1~5점)
- 데이터 정제와 학습/검증/테스트 분할을 다시 수행하지 않고 기존 파일을 그대로 사용한다.

## 3. 모델 및 구현 방법

일반적인 행렬의 직접적인 특잇값 분해(SVD)가 아니라, 추천 시스템에서 Funk SVD로 불리는 **SGD 기반 편향 포함 행렬 분해** 방식을 사용했다.

\[
\widehat r_{ui}=\mu+b_u+b_i+p_u^Tq_i
\]

- `μ`: 학습 데이터의 전체 평균 평점
- `b_u`: 사용자별 평점 편향
- `b_i`: 영화별 평점 편향
- `p_u`: 사용자 잠재 요인 벡터
- `q_i`: 영화 잠재 요인 벡터

관측된 학습 평점에 대해서만 예측 오차를 계산하고, 확률적 경사하강법(SGD)으로 편향과 잠재 요인을 갱신한다. 미평가 항목을 평점 0으로 취급하지 않는다. 모델의 학습에는 정규화(규제) 항을 사용하고 예측 평점은 1~5점 범위로 제한한다. 학습에 없던 사용자나 영화는 가능한 범위에서 전체 평균과 학습된 편향을 사용한다.

- 사용 언어/라이브러리: Python, NumPy, pandas, matplotlib
- 난수 시드: `42`
- **1차 실험** 최대 학습 횟수: 20 Epoch, 조기 종료 대기 횟수(`patience`): 4
- **2차 단일 모델 추가 실험** 최대 학습 횟수: 50 Epoch, `patience`: 6
- **3차 통일 비교** 모든 후보 모델에 최대 50 Epoch, `patience`: 6 적용 (실측 완료)
- 모델 선택 기준: **Validation RMSE 최솟값**
- 가장 좋은 검증 Epoch의 파라미터를 복원하여 모델을 평가한다.
- 별도 `scikit-surprise` 설치 없이 NumPy 기반으로 구현한다.

## 4. 1차 하이퍼파라미터 실험 결과

실제 MovieLens 100K 데이터에서 코드를 실행하여 얻은 결과이다. RMSE와 MAE는 **낮을수록 좋다**. 아래 `선택 Epoch`는 해당 실험에서 검증 RMSE가 가장 낮았던 Epoch로, 반드시 학습 루프가 종료된 Epoch를 의미하지는 않는다.

| 실험명 | 잠재 요인 수 | 최대 Epoch | 학습률 | 규제 강도 | Validation RMSE | Validation MAE | 선택 Epoch |
|---|---:|---:|---:|---:|---:|---:|---:|
| Bias only | 0 | 20 | 0.005 | 0.02 | 0.93253 | 0.73381 | 20 |
| MF-20 | 20 | 20 | 0.005 | 0.02 | 0.93087 | 0.73174 | 20 |
| MF-50 | 50 | 20 | 0.005 | 0.02 | 0.93088 | 0.73158 | 20 |
| **MF-50-reg** | **50** | **20** | **0.005** | **0.05** | **0.92898** | 0.73183 | **20** |
| MF-50-lr | 50 | 20 | 0.010 | 0.02 | 0.93008 | **0.73059** | 11 |

### 실험별 관찰 및 시행착오

1. **Bias only와 잠재 요인 모델 비교:** 가장 좋은 `MF-50-reg`의 RMSE는 `Bias only`보다 **0.00355(약 0.38%) 낮았다**. 잠재 요인 학습으로 RMSE가 개선되었으나 개선 폭은 작았다.
2. **잠재 요인 수 비교:** 동일한 학습률과 규제에서 `MF-20`의 RMSE는 0.93087, `MF-50`은 0.93088이었다. 이번 설정에서는 요인 50개가 20개보다 더 좋은 RMSE를 보이지 않았다. 이 미세한 차이만으로 요인 수의 일반적 우열을 판단할 수는 없다.
3. **규제 강도 비교:** `MF-50`의 규제를 0.02에서 0.05로 높인 `MF-50-reg`는 RMSE가 **0.93088 → 0.92898**로 개선되어 검증 RMSE 기준 최우수 모델로 선택되었다. 다만 MAE는 0.73158에서 0.73183으로 소폭 높아졌다.
4. **학습률 비교:** `MF-50-lr`은 학습률 0.010에서 RMSE 0.93008, MAE 0.73059를 기록했다. **MAE 기준으로는 이 모델이 가장 좋지만**, 이 프로젝트의 모델 선택 기준인 RMSE에서는 `MF-50-reg`보다 낮은 성능이었다. 선택 Epoch는 11이었다.
5. **학습 횟수 한계:** `Bias only`, `MF-20`, `MF-50`, `MF-50-reg` 모두 최대 Epoch인 20에서 가장 좋은 RMSE를 기록했다. 따라서 해당 모델들의 수렴 여부는 이번 실험으로 확정할 수 없으며, 향후 최대 Epoch를 늘리고 Validation 곡선을 추가 확인할 필요가 있다.

## 5. 1차 실험 모델 선택 및 테스트 기록

**Validation RMSE 기준 선택 모델: `MF-50-reg`**

- 잠재 요인 수(`n_factors`): **50**
- 학습률(`lr`): **0.005**
- 규제 강도(`reg`): **0.05**
- 선택 Epoch: **20**

| 평가 데이터 | RMSE | MAE |
|---|---:|---:|
| Validation | **0.92898** | **0.73183** |
| Test | **0.94279** | **0.74737** |

- Test RMSE는 Validation보다 **0.01381** 높았다.
- Test MAE는 Validation보다 **0.01554** 높았다.
- 미관측 테스트 데이터에 대한 일반화 오차를 확인했으나, 이 차이만으로 과적합이 발생했다고 단정할 수는 없다.
- 위 테스트 결과는 **1차로 선택한 모델의 평가 결과**이다. 이후 하이퍼파라미터를 추가 실험할 경우 테스트 데이터 점수를 최적화 기준으로 사용하지 않고 Validation 결과로만 선택한다.

## 6. 2차 실험 — 학습 횟수 확장 (실측 결과)

1차 최고 모델인 `MF-50-reg`(잠재 요인 50, 학습률 0.005, 규제 0.05)에 대해 **최대 Epoch를 50, 조기 종료 `patience`를 6**으로 늘려 별도 학습했다. 데이터 분할과 시드는 동일하게 유지했다.

| 지표 | 1차(최대 20 Epoch) | 2차(최대 50 Epoch) | 변화 |
|---|---:|---:|---:|
| 선택 Epoch | 20 | **34** | +14 Epoch |
| Validation RMSE | 0.92898 | **0.92047845** | -0.00850 (약 0.92% 감소) |
| Validation MAE | 0.73183 | **0.72362927** | -0.00820 (약 1.12% 감소) |
| 실제 종료 Epoch | 20 | **40** | 조기 종료 발동 |

### Epoch별 분석 및 시행착오

- Epoch 20 시점 Validation RMSE = `0.92898437`로 1차 결과와 일치한다.
- **Epoch 34**에서 Validation RMSE가 최소(`0.92047845`)여서 최적 상태로 선택되었다.
- Epoch 35~40 동안 학습 RMSE는 계속 감소(`0.71409 → 0.67471`)했지만 Validation RMSE는 전반적으로 상승했다. 학습 손실 감소와 별개로 **일반화 성능 저하(과적합 징후)**가 나타난 것이다.
- 34 이후 6회 동안 Validation RMSE가 개선되지 않아 Epoch 40에서 조기 종료됐다. 최적 Epoch의 파라미터를 복원하는 구현이므로 사용되는 모델은 **Epoch 34의 가중치**이다.
- Epoch 37의 Validation MAE `0.72339284`는 Epoch 34의 MAE `0.72362927`보다 조금 낮지만, 모델 선정의 사전 기준인 RMSE를 따랐다.
- **2차 모델에 대한 Test RMSE/MAE는 아직 측정한 것으로 보고하지 않는다.** 앞의 `Test=0.94279/0.74737`은 *1차 Epoch 20 모델*의 점수로, 2차 모델의 테스트 점수가 아니다.

### 다음 실험 필요성

2차 실험은 기존 최고 모델 **하나에 대해서만** 최대 Epoch를 늘렸다. 다른 네 후보는 20 Epoch로 제한했기 때문에 당시에는 전체 후보 중 최적이라고 확정할 수 없었다. 이 문제를 해결하기 위해 **3차 실험에서 5개 후보를 동일하게 최대 50 Epoch 및 `patience=6` 조건으로 다시 검증했다.**

## 7. 3차 실험 — 동일 조건의 5개 후보 재비교 및 최종 결과 (실측 완료)

2차 실험에서 `MF-50-reg`만 추가 학습한 한계를 해결하기 위해, **모든 후보에 동일하게 최대 50 Epoch 및 조기 종료 `patience=6`**을 적용했다. 학습/검증/테스트 분할, 난수 시드(42), 각 실험의 모델별 하이퍼파라미터는 유지했다. 아래 수치는 2026-11-06 사용자 PC 실행 출력이다.

| 모델 | 요인 수 | 학습률 | 규제 | Val RMSE ↓ | Val MAE ↓ | 선택 Epoch | 종료 Epoch |
|---|---:|---:|---:|---:|---:|---:|---:|
| Bias only | 0 | 0.005 | 0.02 | 0.93192 | 0.73263 | 28 | 34 |
| MF-20 | 20 | 0.005 | 0.02 | 0.92859 | 0.72696 | 28 | 34 |
| MF-50 | 50 | 0.005 | 0.02 | 0.93038 | 0.73090 | 22 | 28 |
| **MF-50-reg** | **50** | **0.005** | **0.05** | **0.92048** | **0.72363** | **34** | **40** |
| MF-50-lr | 50 | 0.010 | 0.02 | 0.93008 | 0.73059 | 11 | 17 |

### 모델 선택과 최종 Test 성능

사전에 정한 **Validation RMSE 최소화** 기준에 따라 `MF-50-reg`를 최종 선택했다.

- 잠재 요인 수: **50**
- 학습률: **0.005**
- 규제 강도: **0.05**
- 최대 학습 횟수: **50**
- 선택 Epoch: **34** (최고 검증 가중치를 복원)
- 조기 종료 Epoch: **40**

| 평가 데이터 | RMSE ↓ | MAE ↓ |
|---|---:|---:|
| Validation | **0.92048** | **0.72363** |
| Test | **0.93138** | **0.73621** |

3차 최종 모델의 Test RMSE는 Validation RMSE보다 **0.01090** 높다. 이 차이만으로 과적합 여부를 확정할 수 없으며, 학습 곡선 및 다른 분할에서도 검토할 필요가 있다.

### 결과 분석 및 시행착오

1. **기준 모델 대비 개선:** 편향만 사용한 `Bias only`(Val RMSE 0.93192)보다 최종 `MF-50-reg`(0.92048)가 **0.01144, 약 1.23%** 낮았다. 잠재 요인을 포함한 학습이 이 실험에서 실제 개선에 기여했다.
2. **잠재 요인 수 증가가 무조건 유리하지 않음:** 동일한 학습률·규제(0.005/0.02)에서는 `MF-20`(0.92859)이 `MF-50`(0.93038)보다 RMSE가 낮았다. 모델의 표현력이 늘어도 일반화 성능은 별도로 검증해야 한다.
3. **규제 효과:** 50요인·학습률 0.005에서 규제 0.02인 `MF-50`(0.93038)보다 규제 0.05인 `MF-50-reg`(0.92048)의 RMSE가 **0.00990** 낮았다. 이번 후보들 중에는 더 강한 규제가 유리했다. 이를 모든 데이터셋에서 일반화할 수는 없다.
4. **학습률 효과:** 학습률을 0.010으로 높인 `MF-50-lr`는 선택 Epoch가 11이었으며, Val RMSE 0.93008로 최종 모델보다 높았다. 빠르게 종료된다는 이유만으로 더 좋은 모델은 아니다.
5. **학습 횟수 제한 문제 해결:** 1차 최고 모델의 Val RMSE 0.92898(20 Epoch)보다 같은 설정을 확장한 3차 결과가 0.92048(34 Epoch)로 **약 0.92% 개선**됐다. 최대 Epoch를 충분히 확보하고 조기 종료를 적용할 필요성을 확인했다.
6. **평가 지표 일관성:** 1차 실험과 달리, 이번 통일 비교에서는 `MF-50-reg`가 Val RMSE와 Val MAE 모두 가장 낮았다. 최종 모델은 사전 기준인 RMSE로 선택했다.
7. **기존 Test와 비교:** 1차 선정 모델의 Test RMSE 0.94279/MAE 0.74737에서 3차 최종 모델의 Test RMSE **0.93138**/MAE **0.73621**로 감소했다. Test RMSE는 **0.01141, 약 1.21%** 개선됐다. 단, 이 수치는 서로 다른 학습 횟수의 모델 비교다.

### 평가 해석상의 주의점

- 5개 모델은 동일한 최대 Epoch와 조기 종료 규칙을 사용했지만 각 모델의 조기 종료 시점은 달랐다. 이는 **같은 학습 예산과 선택 규칙**을 적용한 비교이지, 모두 같은 횟수만큼 학습한 비교는 아니다.
- 이전 1차 실험에서 이미 Test 점수를 확인했다. 이후 설정을 선택할 때는 Validation 점수만 사용했으나, **Test를 여러 번 확인했으므로 완전히 독립적인 단 한 번의 최종 평가였다고 주장하지 않는다.** 추가 탐색을 계속한다면 별도 미사용 홀드아웃 또는 교차 검증이 바람직하다.
- RMSE·MAE는 평점 예측 정확도를 나타내며, 추천 목록의 다양성이나 Top-K 품질까지 보장하지 않는다. 하이브리드 최종 평가는 통합 단계에서 별도로 고려한다.

- 콘텐츠 기반 추천 점수와 결합할 때의 0~1 정규화 및 하이브리드 가중치 결정은 통합 담당자와 합의한다.

## 10. 한계와 후속 개선 계획

- **학습 수렴 확인:** 3차 통일 비교에서 모든 후보를 최대 50 Epoch, patience 6으로 평가했다. 최종 모델은 Epoch 34에서 가장 낮은 검증 RMSE를 기록하고 Epoch 40에 조기 종료됐다.
- **초기 파라미터 탐색 범위의 한계:** 1차 실험은 요인 수 0/20/50, 학습률 0.005/0.010, 규제 0.02/0.05만 비교했다. 다른 조합의 성능은 알 수 없다.
- **RMSE와 MAE의 차이:** 1차 실험에서는 최우수 RMSE 모델과 MAE 모델이 달랐으나, 3차 실험에서는 최종 `MF-50-reg`가 두 지표 모두 가장 낮았다. 모델 선정 기준(RMSE)은 실험 전부터 일관되게 유지했다.
- **추천 품질 평가의 필요성:** RMSE·MAE는 평점 예측 평가다. 최종 영화 추천 서비스의 Top-K 품질은 향후 Precision@K, Recall@K 또는 NDCG@K 등으로 통합 담당자와 평가 방식을 협의할 수 있다.
- **테스트 데이터 활용 원칙:** 1차와 3차에서 Test를 각각 확인했으므로 이번 결과는 사용한 분할에 대한 관측 성능이다. 이후 Test 수치를 기준으로 재튜닝하지 않으며, 추가 실험 시 별도 미사용 홀드아웃을 확보하는 것이 바람직하다.
