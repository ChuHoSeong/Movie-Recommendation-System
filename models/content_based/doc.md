# Content-Based Filtering (TF-IDF Item Similarity)

## 1. 담당 역할 및 목표

MovieLens 100K의 영화 메타데이터(장르, 제목, 연대)를 이용하여 **TF-IDF 기반 Content-based 추천 모델**을 구현한다. 사용자가 이미 평가한 영화 중 내용이 비슷한 영화의 평점 정보를 이용해 미관측 평점을 예측한다. 팀 제안서에서 이 모델의 목적은 **평가 데이터가 부족한 라이트 유저와 평점이 적은 영화(콜드 스타트)를 메타데이터로 보완**하는 것이다. 전처리 담당자의 공통 데이터 분할을 그대로 사용하며, Model-based 모델과의 점수 결합은 통합 담당자의 역할이다.

## 2. 사용 데이터

- 경로: `data/100k/preprocessed/`
- 학습 데이터: `train.csv` — **70,012건**
- 검증 데이터: `val.csv` — **9,988건**
- 테스트 데이터: `test.csv` — **20,000건**
- 평점 입력 컬럼: `u`(0부터 시작하는 사용자 내부 인덱스), `i`(0부터 시작하는 영화 내부 인덱스), `rating`(1~5점)
- 영화 메타데이터: `items.csv` — 1,682편. 사용 컬럼은 `i`, `title`, `decade`, `year`, 19개 장르 플래그(`unknown`~`Western`)
- 데이터 정제와 학습/검증/테스트 분할을 다시 수행하지 않고 기존 파일을 그대로 사용한다.
- 학습 데이터 기준 사용자당 평가 수는 최소 14, 중앙값 46, 최대 516이다. 학습 데이터에 평점이 **0개인 영화는 56편, 5개 이하인 영화는 477편**(전체 1,682편 중 28.4%)이다.

## 3. 모델 및 구현 방법

### 3-1. 주 모델: TF-IDF Item-Item Content-based (`TfidfContentBased`)

각 영화를 메타데이터 문서로 만들고 TF-IDF 벡터로 변환한 뒤, 영화 간 **코사인 유사도**를 계산한다. 예측 대상 영화와 가장 비슷한 영화 k개 중 사용자가 이미 평가한 영화의 평점 편차를 유사도로 가중평균해 사용자 평균에 더한다.

\[
\widehat r_{ui}=\bar r_u+\frac{\sum_{j\in N_k(i,u)} s_{ij}\,(r_{uj}-\bar r_u)}{\sum_{j\in N_k(i,u)} |s_{ij}|+\lambda}
\]

- `r̄_u`: 사용자 평균 평점 (평가 수가 적은 사용자를 전체 평균 쪽으로 당기는 shrinkage 적용, `mean_shrink=5`)
- `s_ij`: 영화 i와 j의 TF-IDF 코사인 유사도
- `N_k(i,u)`: 사용자 u가 학습 데이터에서 평가한 영화 중 영화 i와 유사도가 높은 상위 k개
- `λ`(`damp`): 분모에 더하는 값. 유사한 영화가 적거나 유사도가 낮을 때 보정값이 과하게 커지지 않도록 사용자 평균 쪽으로 당긴다.

- 장르: 플래그가 1인 장르를 `g_Action` 형태 토큰으로 사용
- 제목: 괄호 안 연도를 제거하고 소문자 영숫자 단어 중 길이 3 이상을 `t_단어` 토큰으로 사용 (불용어 제거는 하지 않았고 IDF가 흔한 단어의 비중을 낮춘다)
- 연대: `d_1990s` 형태 토큰 사용 (값이 `unknown`이면 제외)
- 접두어(`g_`, `t_`, `d_`)로 장르·제목·연대 토큰이 서로 섞이지 않게 했다.
- `TfidfVectorizer(token_pattern=r"\S+", lowercase=False, sublinear_tf=True)` 사용. 벡터는 L2 정규화되므로 내적이 곧 코사인 유사도이다.
- 자기 자신과의 유사도(대각선)는 0으로 둔다.

**콜드 스타트와의 관계:** 유사도는 메타데이터만으로 계산되므로 학습 데이터에 평점이 없는 영화도 예측할 수 있다.

### 3-2. 비교 모델: 유저별 Ridge 회귀 (`ContentBased`)

영화 feature(19개 장르 + 정규화한 개봉연도)에 대해 사용자별 선형 회귀를 학습한다.

\[
\widehat r_{ui}=\bar r_u+x_i^T w_u
\]

- 먼저 전체 사용자의 residual(`평점 − 사용자 평균`)로 전역 가중치 `w_global`을 Ridge로 학습한다.
- 사용자별 가중치 `w_u`는 `w_global`을 기준으로 해당 사용자의 평점으로 Ridge 보정한다. 평점이 적은 사용자는 자동으로 전역 취향을 따른다.
- `reg`: 규제 강도. 클수록 개인화가 약해지고 전역 가중치에 가까워진다.
- 개봉연도는 z-score로 정규화하고, 결측 1건은 중앙값으로 대체했다.

- 사용 언어/라이브러리: Python, NumPy, pandas, matplotlib (TF-IDF 모델은 `scikit-learn` 추가)
- 예측 평점은 1~5점 범위로 제한한다.
- 두 모델 모두 난수를 사용하지 않아 같은 데이터에서 항상 같은 결과가 나온다.
- 모델 선택 기준: **Validation RMSE 최솟값**
- 학습/검증 분리: 후보 비교는 Validation으로만 하고, 선택된 모델에 대해서만 Test를 평가한다.
- MF와 달리 epoch 기반 반복 학습이 없어 조기 종료는 없다. 대신 `k`, `damp`, `reg` 등 설정값을 비교한다.

### 실험별 관찰

1. **연대 feature의 효과(TF-IDF):** 장르만 사용한 `Genre k20`(1.02690)에 연대를 더한 `Genre+Decade k20`(1.01287)은 RMSE가 **0.01403** 낮았다. 이번 실험에서 가장 큰 개선이었다.
2. **제목 feature의 효과(TF-IDF):** 장르에 제목을 더한 `Genre+Title k20`(1.02262)은 장르만 쓴 경우보다 0.00428 낮았다. 그러나 연대가 이미 들어간 상태에서는 제목을 더해도(`G+T+D k20` 1.01256 vs `Genre+Decade k20` 1.01287) 차이가 **0.00031**로 거의 없었다. 이 데이터에서 제목 단어는 평점 예측에 거의 기여하지 않았다.
3. **이웃 수 k(TF-IDF):** k를 10, 20, 50으로 늘리자 RMSE가 1.02016 → 1.01256 → 1.01077로 계속 낮아졌다. 최적이 탐색 범위의 가장자리(k=50)에 있어 더 큰 k에서 더 좋아질 가능성이 있다.
4. **damp(TF-IDF):** k=20에서 damp를 0.5에서 2.0으로 올리자 RMSE가 1.01256에서 1.01362로 소폭 나빠졌다.
5. **규제 강도(Ridge):** `reg=1`(1.05106)은 사용자 평균 기준선(1.03482)보다 오히려 나빴다. 평점이 적은 사용자의 가중치가 과적합된 것으로 해석된다. `reg`를 5, 20으로 키울수록 개선됐고, 개봉연도를 포함한 설정에서는 `reg=20`이 최저였으며 50, 100에서는 다시 소폭 상승했다.
6. **개봉연도의 효과(Ridge):** 같은 `reg`에서 개봉연도를 추가하면 `reg=5`에서 0.01708, `reg=20`에서 0.01664 낮아졌다.
7. **장르만의 한계:** 전역 장르 가중치(`Global genre`, 1.03442)는 사용자 평균 기준선(1.03482)과 거의 같았다. 장르 자체는 평점 예측 정보가 많지 않다.

## 5. 모델 선택 및 테스트 기록

Validation RMSE 기준으로 각 계열에서 최우수 설정을 선택했다.

**주 모델(TF-IDF): `G+T+D k50`** — 장르+제목+연대, 이웃 수 50, damp 0.5, mean_shrink 5

**비교 모델(Ridge): `CB-reg20-year`** — 장르+개봉연도, reg 20, mean_shrink 5

| 모델 | Validation RMSE | Validation MAE | Test RMSE | Test MAE |
|---|---:|---:|---:|---:|
| User mean only (기준선) | 1.03482 | 0.83239 | 1.04704 | 0.84181 |
| **TF-IDF `G+T+D k50`** | **1.01077** | **0.80990** | **1.02280** | **0.81965** |
| Ridge `CB-reg20-year` | 0.99546 | 0.79548 | 1.00417 | 0.80208 |

- 사용자 평균 기준선 대비 Test RMSE 개선: TF-IDF **0.02424(약 2.32%)**, Ridge **0.04287(약 4.09%)**
- TF-IDF의 Test RMSE는 Validation보다 0.01203 높았고, Ridge는 0.00871 높았다. 이 차이만으로 과적합 여부를 확정할 수 없다.
- **제안서 명세(TF-IDF)를 주 모델로 삼았지만 Ridge가 모든 지표에서 더 좋았다.** 통합 시 어느 쪽을 사용할지는 통합 담당자와 합의한다.

### 분석 및 해석

1. **라이트 유저에서 개선 폭이 가장 작다.** 사용자 평균 대비 TF-IDF 개선은 0~30구간 0.0068(약 0.64%), 120 이상 구간 0.0319(약 3.04%)로, 평가 수가 많을수록 커졌다. 사용자의 과거 평점 기록으로 취향을 추정하는 방식이라 기록이 적으면 이웃 정보가 약하다. 콜드 스타트 완화 기대와 달리 **기록이 적은 사용자에서 이 방식의 이득이 작다**는 점을 확인했다.
2. **평점이 적은 영화에서도 개선이 크게 두드러지지는 않는다.** TF-IDF의 상대 개선은 1~5구간 약 1.7%, 21 이상 구간 약 2.3%로 비슷했다.
3. **평점이 0개인 영화(44건)** 는 TF-IDF가 사용자 평균과 RMSE가 같게 나왔다(1.0020). 예측값 자체는 사용자 평균과 다르지만(최대 0.46점 차이), 표본이 44건으로 매우 작아 해석하기 어렵다.
4. 모든 구간에서 Ridge가 TF-IDF보다 낮은 RMSE를 보였다.

## 7. 한계와 후속 개선 계획

- **정보량이 적은 feature:** 100K의 메타데이터는 장르 19개, 제목, 개봉연도뿐이다. 줄거리·감독·배우 같은 텍스트가 없어 TF-IDF의 이점이 제한적이다. 1M 확장 시에도 같은 한계가 예상된다.
- **탐색 범위의 한계:** `k`는 10/20/50, `damp`는 0.5/2.0, `reg`는 1~100 범위만 비교했다. `mean_shrink`(5)는 튜닝하지 않고 고정했다. k=50이 탐색 범위의 끝이므로 더 큰 값은 확인하지 못했다.
- **연대 외 연도 정보:** TF-IDF 모델은 연대 토큰(범주)만 사용한다. Ridge 모델처럼 개봉연도를 연속값으로 반영하면 개선될 가능성이 있으나 시도하지 않았다.
- **신규 사용자:** 학습 평점이 전혀 없는 사용자는 전체 평균을 반환한다. 이 경우를 위한 별도 설계(예: 인구통계 기반)는 포함하지 않았다.
- **추천 품질 평가의 필요성:** RMSE·MAE는 평점 예측 평가다. Top-K 품질(Precision@K, Recall@K, NDCG@K)은 통합 담당자와 협의한다.
- **테스트 데이터 활용 원칙:** 후보 선택은 Validation으로만 했고, 선택된 모델의 Test를 평가했다. 6절의 구간 분석도 Test를 사용했으나 선택에는 사용하지 않았다. 이후 Test 수치를 기준으로 재튜닝하지 않는다.

- 데이터 폴더(`data/100k/preprocessed`)는 파일 위치에서 위로 올라가며 자동 탐색하므로 실행 위치에 상관없이 동작한다.

**통합 인터페이스:**

| 항목 | TF-IDF 모델 | Ridge 모델 |
|---|---|---|
| 클래스 | `TfidfContentBased` | `ContentBased` |
| 생성 | `TfidfContentBased(n_users, items, features, k, damp, mean_shrink)` | `ContentBased(n_users, item_features, reg, mean_shrink)` |
| 학습 | `fit(train)` | `fit(train)` |
| 예측 | `predict(u, i)` | `predict(u, i)` |

- `items`는 `items.csv`를 읽은 DataFrame, `item_features`는 `load_item_features()`가 만드는 행렬이다.
- `fit`은 `BiasedMF.fit(train, val)`과 달리 **`train`만** 받는다. 반복 학습이 없어 검증 데이터가 필요하지 않다.
- 입력: 전처리된 **0-based** 사용자/영화 내부 인덱스 `u`, `i` (스칼라 또는 배열)
- 출력: 예측 평점(1~5 범위). `BiasedMF.predict`와 같은 척도라 척도 변환이 필요하지 않다.
- 범위를 벗어난 사용자 인덱스는 전체 평균, 범위를 벗어난 영화 인덱스는 사용자 평균을 반환한다.
- 하이브리드 결합 시 0~1 정규화가 필요하면 `(r − 1) / 4`로 변환할 수 있으며, 정규화 방식과 가중치 결정은 통합 담당자와 합의한다.
- 하이브리드에서 어느 content-based 모델(TF-IDF 또는 Ridge)을 쓸지는 통합 담당자와 합의한다.
